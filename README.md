# tensarflow/homebrew-tap

Homebrew casks for [tensarflow](https://github.com/tensarflow)'s apps.

```sh
brew install --cask tensarflow/tap/phonecam
```

| Cask | App |
|---|---|
| `phonecam` | [PhoneCam](https://github.com/tensarflow/PhoneCam) — use an Android phone as a USB webcam and microphone on macOS |
